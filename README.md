# DeckJSON

人與 AI 協作設計簡報的本地單檔 HTML 工具。在 16:9／4:3／自訂尺寸的畫布上擺放文字／表格／圖片／形狀／圖表／影片，匯出原生 `.pptx`——位置、大小、字體、格式如實呈現，不是把畫面截圖貼進投影片。

## 特色

- **單檔、離線、零安裝**：下載 `deckjson.html`，雙擊用瀏覽器打開就能用。不需要帳號、不需要伺服器，**不連任何外部網域**（字體用你電腦上已安裝的，不下載網路字體），內容不會離開你的電腦。
- **原生 pptx 幾何保真**：形狀、表格、文字框都是真正的 OOXML 元件，不是圖片。匯出的 PowerPoint 黃色調整點（`adj`，如圓角、梯形斜度）仍然可以拖動。
- **完整 176 種內建形狀**：矩形／基本圖案／箭號／方程式／流程圖／星星綵帶／圖說／動作按鈕，等同 PowerPoint 的整份形狀清單，可搜尋。畫布上的輪廓**就是 PowerPoint 的原生幾何本身**——由 OOXML 的 preset 幾何定義即時求值，不是手畫的近似路徑；其中 114 種帶黃色調整點，拖曳手感與 PPT 一致；形狀內的文字也照 preset 各自定義的**文字區**擺放（187 種裡 137 種不是整個外框，且隨黃點連動）。清單裡沒有的異形可用 **自訂幾何（custGeom）**：內建**圖形編輯器**（鋼筆畫線與貝茲、拖曳控制柄、線段插點、格線吸附、子路徑挖洞），也可直接以座標陣列描述交給 AI 產生。內建形狀想改細節時按「**轉成可編輯端點**」即可原地拆成端點（同 PowerPoint 的「編輯端點」，外觀不變，187 種全部驗過最大偏差 0.04px）。
- **自動存檔**：每次改動後約 1 秒存進瀏覽器（IndexedDB），重新整理或關掉分頁再打開會自動還原，頂端顯示存檔時間；存不進去（容量滿、無痕模式）一律轉紅字明講原因，不靜默失敗。另有 `📄 開新`／`📂 開啟`／`💾 另存`（Cmd/Ctrl+S）讀寫 `.deck.json` 檔——自動存檔只有一份且只在這台瀏覽器，重要進度請另存成檔案。
- **JSON 是第一公民**：整份簡報就是一份 JSON。可以把 JSON 複製給 AI 助手，請它幫你調整版面或內容，再貼回工具套用；也可以直接在畫布上手動微調——兩者共用同一份資料，不會互相打架。
- **環境設定檔（profile）**：投影片尺寸、字體三槽、語言、母版預留區（Logo 位／頁尾…）、頁碼樣式、檔案屬性都是**資料**而非寫死的常數——可匯出成 `.profile.json` 帶著走、設為新簡報預設，或在打包時內嵌成出廠值。設定同時存在簡報 JSON 裡，貼給 AI 再貼回來不會掉。
- **雙字體模式**：鎖定字體或依母版繼承，中西文分開指定，行距精確鎖定不跑版（貼上不同母版也不會位移）。
- **母版（信紙）**：Logo／頁尾／裝飾條放在一份共用的「信紙」上，墊在每一頁底下，改一次全部頁面跟著變（單頁可關）。編輯母版時畫布整個切過去，一般工具全部照用——文字、形狀、圖片、圖表、漸層、陰影、超連結、自訂幾何都能放。匯出方式二選一：**放在母版上**（寫進 PowerPoint 的版面配置，檔案最小）或**畫進每一頁**（母版內容變成每頁真正的圖形，單張投影片複製到別的簡報也帶得走）。切換只改一個旗標，不動母版內容。刻意**不做 placeholder**：那種「按一下以新增標題」的洞會在貼到別的母版時跳位，與本工具的幾何保真前提相衝。
- **Morph 平滑轉場**：頁面屬性一鍵設定，匯出後 PowerPoint 原生播放（依元素 id 跨頁配對；「複製此頁」改版面即成動畫），舊版 PPT 自動退回淡出。
- **就地富文本編輯**：雙擊文字框直接改，粗體與顏色看得見；**反白幾個字，格式按鈕就只套那幾個字**，跟 Word 一樣的手感。同一句話裡混用粗體、顏色、字級，匯出後在 PowerPoint 內仍是同一個文字框裡的一句話，不會被切成好幾個文字方塊。JSON 也接受 `"md": "這是**粗體**文字"` 這種簡寫給 AI 用，套用時展開成正式結構。
- **表格儲存格也能格內混排**：`Fe₃O₄`、`10⁻³` 這類化學式與科學記號，在同一格裡就能同時有下標、上標、變色、變字級——雙擊進格反白幾個字即可，不必把該格留空再疊一個文字框。JSON 端只需寫「和整格不一樣的地方」（`runs`，同樣吃 `md` 簡寫），大表格不會因此膨脹到 AI 讀不動。
- **原生文字格式**：底線／刪除線／高亮／字距／描邊／輝光／自訂字型、上下標、項目符號與編號清單（含縮排層級）、段前後間距、超連結（外部網址或跳頁）——匯出全是 PPT 原生字元與段落屬性，不是圖片效果。
- **漸層填色**：文字框與形狀可設線性（可調角度）或放射狀漸層，2–6 個色標。PptxGenJS 沒有原生 API，改以匯出後注入 `<a:gradFill>` 達成，在 PowerPoint 內仍可再調。
- **直書與文字方向**：中日韓直書、旋轉 90°／270°、蒙文直書，匯出為原生 `<a:bodyPr vert>`——文字在框內轉向，框本身不轉。畫布用 CSS `writing-mode` 對上預覽，直書時中文直立、英數躺下，與 PowerPoint 一致。
- **圖表：資料歸 JSON，外觀歸面板**：圖表資料就是 ECharts option（自己寫或整份丟給 AI 產）；「視覺編輯」分頁只調外觀，面板頂端**即時預覽**改動結果——圖種（直條／橫條／折線／區域／圓餅／環圈，可互換且標籤數值逐項保留）、圖表與座標軸標題（字級／顏色）、軸線與刻度（顏色／粗細）、軸標籤（字級／顏色／傾斜角）、數值軸最小最大／刻度間隔／反轉、主格線（顏色／線寬／實虛點）、圖例（位置／字級／顏色）、資料標籤（位置／字級／顏色）、系列顏色與邊框、柱寬、線寬與端點、圓餅內圈與起始角、繪圖區留白、圖表底色。**面板只寫它自己那幾格**，手寫的 `markLine`、`tooltip`、`visualMap` 不會被覆蓋；表達不了的（如自訂 `formatter` 樣板）直接鎖住並說明，不會顯示成空白誘導你蓋掉。
- **原生／PNG 界線是明示的**：面板上每個設定都標清楚有沒有 PowerPoint 原生對應。沒有的（長條圓角、副格線、隱藏數值軸標籤）掛「僅 PNG」角標；一旦勾了「匯出為原生圖表」就**直接停用**，不讓你設一個匯出時會靜靜消失的值。反過來，勾原生時若既有 option 已含這類設定，會在勾選前就列出將不保留的項目。
- **圖表雙輸出**：圖表資料只有一份 ECharts option，匯出時可二選一——預設 3 倍解析度 PNG（外觀與畫布完全一致），或勾選「匯出為原生圖表」變成 PowerPoint 原生圖表（PPT 內能按「編輯資料」改數字、跟隨目標母版）。勾／取消勾都不動 option，可隨時切回來比較。桑基、儀表板、熱力圖等沒有 OOXML 對應的圖種，勾選框會直接灰掉並寫明原因；同一頁可原生與 PNG 混用。
- **原生陰影與圖片裁切**：文字框／形狀／圖片／圖表可設 PPT 原生投影（`outerShdw`）；圖片可「填滿裁切」（原生 `srcRect`）或圓形裁切，並可填無障礙替代文字。
- **章節**：頁面可標記為章節起點，匯出為 PowerPoint 原生章節——縮圖窗格可整段摺疊、搬動、隱藏、從該段開始放映。只影響編輯時的導覽，投影片內容與放映不變。
- **頁碼與頁面背景**：自動頁碼為原生欄位（插刪頁自動更新，可設位置／字級／顏色／首頁不顯示）；頁面背景圖匯出為原生 `<p:bg>`；作者／公司／主旨寫入檔案屬性。
- **影片**：YouTube 連結匯出為 PPT 原生線上影片（pptx 內只有封面圖，不含影片位元組）；本機影片則自動抓一格當封面佔位，匯出後列出「待插入影片」清單，請在 PowerPoint 換成真影片——刻意不嵌入位元組，以保住「整份 JSON 貼給 AI」這個用法。
- 圖層面板、透明度、軟群組、對齊分佈、格式刷、色票系統、範本庫、Deck 合併、快照匯出（PNG/JPG）、講者備忘稿、形狀 adj 黃點（畫布直接拖曳，同 PPT 手感：圓角／箭號桿寬箭頭／圖說框尾標／肘形折點…）、Cmd/Ctrl+C/V 跨頁跨檔複製元素、表格逐格框線（實線／虛線可混用）、線條與外框線型、物件層級超連結（含提示文字）、文字框內距／不換行、不放映此頁。

## 使用方式

1. 下載 `deckjson.html`
2. 用瀏覽器開啟（Chrome / Edge / Safari 皆可）
3. 在畫布上新增元素，或用「JSON」按鈕貼入既有簡報結構
4. 完成後按「匯出 pptx」，用 PowerPoint / Keynote / Google Slides 開啟即可繼續編輯

## 開發

原始碼在 `src/`：

- `src/index.html`：主程式（無框架、純 JS）
- `src/vendor/`：簽入版控的第三方函式庫（見 [THIRD-PARTY-LICENSES.md](THIRD-PARTY-LICENSES.md)）
- `src/build.sh`：打包腳本

```bash
bash src/build.sh   # 將 src/index.html 與 vendor/*.js 內聯打包，輸出（覆蓋）根目錄的 deckjson.html
```

若你有一份固定的環境設定（公司母版的預留區、指定字體…），可以把它內嵌成該份成品的出廠預設，原始碼不需分岔：

```bash
bash src/build.sh --profile my.profile.json --out ../deckjson-mine.html
```
