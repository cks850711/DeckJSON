插入形狀
176 種形狀，等同 PowerPoint 內建清單，匯出為原生幾何（prstGeom），可在 PPT 內再調整。畫布輪廓由 OOXML preset 幾何定義即時求值，不是近似圖形。縮圖右上角有黃點者可調整：選取後直接拖曳畫布上的黃點（同 PPT 手感），或用右欄滑桿微調。線條類（含肘形雙箭頭）選取後拖曳兩端圓點改方向，接近水平／垂直自動貼齊；肘形連接線另有黃點可調直角折點。最後一組「自訂幾何」給清單裡沒有的異形用，插入後直接開圖形編輯器（鋼筆畫、拖點改），也可在 JSON 面板改 points——它在 PPT 內不會有黃點，能用內建形狀就別用它。想改內建形狀的細節，選取後用右欄「形狀 → 幾何」的「轉成可編輯端點」把它拆成端點再改（同 PPT 的「編輯端點」，單向不可逆）。

貼上 ECharts option 的 JSON（不支援函式）。資料（類別、數值、系列名）在這裡改，外觀請用「視覺編輯」分頁。預設以 3 倍解析度 PNG 匯出；側欄勾「匯出為原生圖表」可改為 PowerPoint 原生圖表。
地圖：{"type":"map","map":"名稱"} 的幾何資料存在整份簡報的 maps 欄位，用上面的按鈕匯入 GeoJSON；PowerPoint 沒有原生地圖，一律以 PNG 匯出。
插入影片
匯出為 PPT 原生線上影片（<a:videoFile> 外部連結）：pptx 內不含任何影片位元組，只有一張封面圖。播放時需要網路。網址可直接貼 watch／youtu.be 形式，會自動轉成 PowerPoint 需要的 embed 形式。
本機影片不會嵌入（20MB 的 mp4 base64 後約 27MB，會塞爆「整份 JSON 貼給 AI」這個用法）。工具只自動抓一格畫面當封面＋記下檔名與長度，匯出後會列出「哪幾頁待插入影片」，請在 PowerPoint 對照該框插入真影片。
匯出完成待插入影片清單
這些頁只放了封面圖佔位。請在 PowerPoint 開啟該頁，於同一個框的位置「插入 → 視訊」換成真影片（封面圖可直接刪除）。同一份資訊也寫進了各元素的替代文字與該頁備忘稿。
