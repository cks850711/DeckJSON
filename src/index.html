使用說明

這是什麼

人與 AI 協作設計簡報的單檔工具：在畫布上擺放文字、表格、圖片、形狀、ECharts 圖表與影片，匯出原生 PPTX，位置、大小、格式如實呈現（EMU 精確座標、行距鎖定）。全程本機處理，不連任何外部網站（字體用你電腦上已安裝的，不下載網路字體）。

與 AI 協作

  • 右上「JSON」＝整份簡報＋全域（標題／字體模式／字型／語言／投影片尺寸／預留區）：複製給 AI 討論 → 貼回「套用」。環境設定跟著 JSON 走，所以貼來貼去不會掉。
  • 右欄「本頁 JSON ▤」＝可拖曳的浮動面板，只顯示目前頁；面板開著時點畫布任一元素／圖片，會自動捲動並選取它的 JSON 區塊，適合針對性微調。
  • JSON 內圖片以 @asset:元素id 佔位顯示（base64 不塞爆視窗）；「套用」時自動還原位元組。新圖請由工具插入；存 .json 檔仍含完整圖片。
  • 細緻的格式（單一文字框內混用粗體／變色／上下標／底線／高亮／逐段項目符號、儲存格個別底色、合併儲存格）由 AI 直接寫 JSON 達成；畫布上的編輯以整個元素為單位（面板操作一律套用到該元素的全部 run／段落）。
  • 圖表存的是 ECharts option 規格，不是死圖——隨時可改數據重渲染。

存檔

  • 自動存檔：每次改動後約 1 秒自動存進瀏覽器（IndexedDB），重新整理／關掉分頁再打開會自動還原，頂端會顯示存檔時間。存不進去時（容量滿、無痕模式）會轉紅字明講原因，不會靜默失敗。
  • 📄 開新：清空重來，需連按兩次確認；還留一步 Cmd/Ctrl+Z 後路。📂 開啟／💾 另存：讀寫 .deck.json 檔（Cmd/Ctrl+S 直接另存）。
  • 自動存檔只有一份、只在這台瀏覽器。重要進度請另存成檔案——那才是可備份、可轉移、可貼給 AI 的形式。

畫布操作

  • 點選→拖曳移動（有置中／邊界磁性吸附）；八個把手縮放；方向鍵微調（Shift=10px）；Delete 刪除；Cmd/Ctrl+D 複製元素。
  • 多選：Shift／Cmd 點擊加減選，或在空白處拖曳框選；多選後拖四角＝整組比例縮放（位置、尺寸、字級同步）、拖本體＝整組移動，右欄可輸入縮放 % 與對齊。
  • 雙擊文字／形狀＝就地編輯文字，粗體、顏色、高亮都看得見也改得動：反白幾個字，右欄的格式按鈕就只套那幾個字（沒反白＝套用整個文字框）。編輯中點右欄按鈕不會中斷編輯，反白範圍會保留。雙擊表格儲存格＝編輯內容；雙擊圖表＝編輯 option。
  • 右欄的純文字編輯框是「整框覆寫」用的捷徑，會清掉框內的混排格式——若偵測到混排會先跳確認。要保留格式請在畫布上就地編輯。
  • 「＋形狀」開啟圖庫：線條／矩形／基本圖案／箭號／方程式／流程圖／星星綵帶／圖說／動作按鈕，共 176 種，另有自訂幾何。線條類（直線、箭頭、雙頭、肘形）選取後拖曳兩端圓點改方向，可水平、垂直、斜向；畫布輪廓即 OOXML 原生幾何，匯出為 PPT 原生幾何。
  • 表格選取後：上緣／左緣藍色把手調欄寬列高；把手之間的灰色區段滑過變紅、點擊即刪除該欄／列（合併儲存格自動縮減，其餘欄寬列高不動）；右側面板「新增」加欄列。
  • 合併儲存格：表格選取後，在格子內拖曳反白要合併的相鄰範圍（會自動外擴，不切穿既有合併），點反白框旁的「合併儲存格」鈕；反白單一已合併格則點「取消合併」。此時移動整張表改由拖曳表格邊框帶（外圈約 16px）。雙擊某格＝編輯該格文字。
  • 逐格／多格改樣式：拖曳反白幾格後，右側面板的字級／行距／粗斜體／文字色／對齊／底色／框線只套用到選取格（面板頂端會顯示套用範圍）；未反白則套用全表。
  • 逐格框線：右欄「框線筆」設線寬（pt）＋顏色，再點全部／外框／內部／上／下／左／右／無套到反白範圍（未反白＝全表）。每格四邊、顏色線寬各自獨立（同 PowerPoint 儲存格框線）；相鄰共用邊自動雙寫同步，故畫布預覽＝匯出結果。
  • 格內編輯快捷：編輯儲存格時，Tab＝跳右一格（列尾自動換到下一列、跳過合併格）、Shift+Tab＝跳左一格、Enter＝跳下一格、Shift+Enter＝格內換行、Esc＝結束編輯。（PowerPoint 的 Enter 是格內換行；此處 Enter 改採試算表式跳下格，換行請用 Shift+Enter。）
  • 右欄「縮放 %」＝單一元素等比縮放（尺寸、字級、欄寬列高、線寬同步，可小數）；圖片與形狀另有角度／90°／水平垂直翻轉。
  • 物件拖出投影片外仍半透明可見、可拖回；超出區域僅供暫放，匯出時照座標輸出（會有超出警告）。
  • 圖片：「＋圖片」選檔，或直接把圖檔拖進畫布、貼上剪貼簿圖片；縮放固定等比。
  • ☰ 圖層面板（頂端按鈕，可拖曳）：列出當頁元素（上＝最上層），拖曳重排堆疊、👁 顯示／隱藏、🔒 鎖定（畫布不可選拖，仍可從面板點選）；點列選取（群組則選全組）。隱藏元素不渲染也不匯出。
  • 不透明度：右欄滑桿 0–100%，匯出轉 PPT 原生 transparency（圖片／形狀填色／框線／表格底色可調）。
  • 軟群組：多選後按「群組」；之後點群組任一成員即選全組並可整組移動／縮放，雙擊可進入編輯單一成員；單選面板或多選面板可「解散」。匯出時攤平為獨立元素。
  • 對齊分佈：多選面板有左/中/右、上/中/下對齊，及水平／垂直等距（需 ≥3 個，首尾固定、中間平均間隙）。
  • 格式刷：選來源元素按「🖌 複製樣式」武裝（游標變 copy、頂端提示），再點目標套用其字體／顏色／對齊／填色／框線／不透明度（不改內容與尺寸）；可連續套多個，Esc 取消。
  • 縮放：右欄滑桿 0.1–2.0×（停頓於 0.5／0.8／1.0／1.2／1.5），旁邊「含字級」勾選（預設開）；放開歸回 1.0×。寬高旁「比例鎖定／字級同步」勾選（預設關）影響數字輸入與拖曳 resize。
  • 行距：文字框與表格可設行距（×字級），匯出鎖為精確 spcPts；單格行距可透過 JSON 微調。
  • 文字格式：除粗斜體外另有 U 底線／S 刪除線、高亮（螢光筆色塊）；「字元進階」有字距、自訂字型（只覆寫此元素，留空＝沿用全域字體模式）、描邊與輝光。全部匯出為 PPT 原生字元屬性。以上每一項都能只套用到反白的那幾個字——同一句話裡混用粗體、顏色、字級都可以，匯出後在 PowerPoint 內仍是同一個文字框裡的一句話（不是被切成好幾個文字方塊）。
  • 給 AI 的簡寫：JSON 的段落可以只寫 "md" 欄位代替 runs，支援 **粗體**、*斜體*、~~刪除線~~、==高亮==、[文字](網址)（[文字](#3)＝跳頁）。套用時會展開成正式的 runs 並移除 md，存檔裡不留 markdown。text 欄位永遠是字面文字、不會被解析，所以內容本來就含 ** 也不會被改壞。
  • 項目符號／編號：「段落」區可切 無／• 符號／1. 編號，並用 −／＋ 調縮排層級（每層 18pt＝PPT 預設 0.25 吋，懸掛縮排）；匯出為原生 buChar／buAutoNum，在 PPT 內仍是真正的清單。另可設段前／段後間距（與行距獨立）。
  • 超連結：填網址，或填 #3 跳到本簡報第 3 頁。設了連結的文字會自動加底線（PptxGenJS 一律補 u="sng"，預覽同步顯示），顏色仍照你設定的文字色。
  • 原生陰影：文字框／形狀／圖片／圖表的「陰影」區勾選後可調顏色／模糊／位移／方向／濃度，匯出為 PPT 原生 outerShdw（不是截圖效果，PPT 內可再調）。畫布用 CSS filter 預覽，快照 PNG 不會有陰影（html2canvas 不支援 filter）。
  • 圖片裁切：預設「完整」＝整張塞進框、強制等比不變形；切「填滿裁切」後寬高可各自調整，圖片填滿框、裁掉超出部分（匯出為原生 srcRect）。另有「圓形裁切」與「替代文字」（無障礙 descr）。
  • 表格虛線框線：框線筆旁勾「虛線」再套（全部／外框／內部／各邊），匯出為 prstDash sysDash；實線虛線可逐格逐邊混用。
  • 頁面背景圖：頁面面板「🖼 背景圖」選圖，滿版拉伸、壓在所有元素之下，匯出為原生 <p:bg>。要局部裁切請改用一般圖片元素鋪滿整頁。
  • 自動頁碼：頁面面板「頁碼（整份簡報）」勾選後可選左下／中下／右下、字級、顏色、首頁不顯示；匯出為原生頁碼欄位（<a:fld type="slidenum">，插入／刪除頁會自動更新），位置落在底部頁尾預留區。畫布上的頁碼是預覽，不可選取。
  • 檔案資訊：頁面面板可填作者／公司／主旨，連同標題寫入 pptx 檔案屬性（Finder／PowerPoint「資訊」看得到）；留空則不寫入該欄位。
  • 線型：形狀外框、線條、文字框框線可選實線／點線／虛線／長虛線／點虛線／長點虛，匯出為原生 prstDash（表格框線另有自己的實／虛線開關）。
  • 物件超連結：形狀／圖片／圖表／線條可設「整個物件可點」的連結（外部網址或 #3 跳頁），另可填滑過時的提示文字。文字框內個別文字的連結請用「文字樣式 → 超連結」。
  • 文字框內距／不換行：內距讓有填色的卡片式文字框不再貼邊（匯出為 lIns/tIns/rIns/bIns）；「不自動換行」適合單行標籤（匯出 wrap="none"）。
  • 不放映此頁：頁面面板勾選後該頁仍在檔案裡、放映時跳過（匯出 <p:sld show="0">），縮圖會壓暗並標示。
  • 影片（頂端「＋影片」）： YouTube 連結＝匯出為 PPT 原生線上影片，pptx 內只有封面圖、影片走外部連結（播放需要網路）； 本機影片＝不嵌入位元組，只自動抓一格畫面當封面並記下檔名長度，匯出後跳出「待插入影片」清單，請在 PowerPoint 對照該框插入真影片（同一份提示也寫進替代文字與該頁備忘稿）。封面可隨時換成自己的圖。
  • 形狀庫（176 種）：矩形／基本圖案／箭號／方程式／流程圖／星星綵帶／圖說／動作按鈕，等同 PowerPoint 內建的整份形狀清單。上方可用中文名或英文 key 搜尋。畫布上看到的輪廓就是 PowerPoint 的原生幾何本身（由 OOXML 的 preset 幾何定義即時求值），不是近似圖形。
  • 形狀 adj 黃點：可調形狀選取後，畫布上會出現黃點，直接拖曳調整圓角／斜度／箭深／桿寬／尾標／角度／肘形折點（同 PPT 手感，拖曳時顯示百分比）；右欄滑桿可精修，匯出為 PPT 原生 avLst。形狀選單縮圖右上角有黃點者即支援，114 種形狀有黃點。沒動過就不寫入，交給 PowerPoint 用它自己的預設值。
  • 自訂幾何（custGeom）：形狀庫最後一組，給清單裡找不到的異形用（不規則色塊、自訂折線、資訊圖區塊）。插入後直接開圖形編輯器；已存在的自訂幾何選取後按右欄「✎ 開啟圖形編輯器」。也可在 JSON 面板改 points，或請 AI 產生——指令有 moveTo／直線／二次貝茲／三次貝茲／圓弧／close。
  • 圖形編輯器：鋼筆點一下＝角點、按住拖＝帶曲度的平滑點、點回黃色起點＝閉合，Esc／雙擊結束後再點就是新的子路徑。編輯點可拖錨點、拖控制柄調曲度（Alt 拖＝兩側拆開成折角）、點線段在正中插節點、雙擊錨點切換直線／曲線、Delete 刪點。另有格線吸附（間距可選）與編輯器內獨立的 Cmd/Ctrl+Z。挖洞要讓內圈與外圈反向繞行（PowerPoint 用 nonzero 填充規則），畫完內圈按「⇄ 反轉方向」即可。
  • 自訂幾何會跟著形狀縮放：座標活在形狀自己的路徑座標空間（pathW／pathH），拉大拉小圖案等比跟著變，與 PPT 內建形狀的行為一致。
  • 色票：所有選色開三頁籤面板——設計師精選（每組 5 色）／Open Color（14×10）／全色域調色盤。
  • 範本庫：頁面面板「📋 套範本」插入標題頁／兩欄／圖表頁等版型（文字帶 role）。Deck 合併「⧉ 合併 .json」把另一份簡報附加為後續頁。
  • 快照匯出：頂端「🖼 快照」輸出本頁或全部（zip）為 PNG／JPG，可選 1–3× 解析度。講者備忘稿在頁面面板編輯，匯出寫入 pptx。
  • 所有元素（表格除外）有淡虛線框顯示框尺寸；圖片／形狀旋轉後選取框與把手跟著轉（resize 已依旋轉換算，仍正確）。
  • 右側面板分組：位置尺寸（X 上方可切 px／pt／cm，預設 px）／版面（縮放、不透明、置中、角度翻轉）／內容樣式（依類型：文字／線條／形狀／圖片／表格／圖表；文字再細分字元進階／段落／超連結／陰影，表格再細分結構／儲存格樣式／框線／合併）／排列（層級）／動作（格式刷、複製、刪除）。未選取任何元素時顯示頁面屬性，其中「頁碼」「檔案資訊」「投影片尺寸」「字體」「預留區」「環境設定檔」六區是整份簡報層級。
  • 復原／重做：Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z（60 步）。

簡報設定（右欄「頁面」）

  • 投影片尺寸：16:9／4:3／16:10 或自訂 px。改尺寸不會自動搬動既有元素，需自行重排。
  • 字體：中文／英數／表格英數三槽，填你電腦上已安裝的字體名，畫布即時反映、匯出寫同一個名字。未安裝時頂端會提示「預覽用替代字體，匯出仍寫原字體名」。
  • 語言：寫入每個文字 run 的 lang，決定 PowerPoint 用哪國拼字檢查（預設跟隨瀏覽器語言）。
  • 預留區：母版上不該被壓到的區域（Logo 位、頁尾…），可加可刪。只是畫布輔助線與吸附，元素壓到會變紅警告但不阻擋，不寫入 pptx。預設沒有任何預留區。
  • 環境設定檔（profile）：把上面這些（含頁碼樣式與檔案屬性）整包匯出成 .profile.json，或載入套用；也可「設為新簡報預設」記在這台瀏覽器。設定同時存在簡報 JSON 裡，所以貼給 AI 再貼回來不會掉。

字體模式

  • 鎖定字體（預設）：匯出寫死你設定的三個字體名。預覽＝輸出，折行位置最可靠。
  • 母版繼承：匯出寫 +mn-lt／+mn-ea 主題槽引用，貼到任何母版時由該母版字體接手（折行位置隨目的端字體浮動）。
  • 兩種模式都不按語言切 run、全文件同一個 lang——xlsx2pptx 的中英交界異常換行病灶已拔除。

匯出行為

  • 每頁一張投影片；文字框關閉 autofit、行距鎖定 1.2 倍字級精確值；表格為原生 PPTX 表格；圖片嵌原始位元組；圖表以 3× PNG 嵌入。
  • 匯出後會修掉 PptxGenJS 3.12 的幾個結構性缺陷（段內混排時重複輸出 <a:pPr>、頁碼佔位形狀 id 寫死撞號、物件超連結沒註冊關聯而寫出懸空 rIdundefined、備忘稿基建畸形等），以免 PowerPoint 判為毀損要求修復。
  • 每個元素的 pptx 形狀名稱＝其 JSON id（日後 Morph 轉場跨頁配對用）。
  • 使用方式：開啟匯出的 .pptx，整頁複製到目標簡報（目標簡報的尺寸需與此處設定相同，否則會被縮放）。

已知限制

  • 母版繼承模式下折行位置由目的端字體決定，文字框寬度請留餘裕。
  • ECharts option 僅支援純 JSON（不含函式）。
  • 陰影在快照 PNG 不呈現（html2canvas 不支援 CSS filter）；匯出 pptx 不受影響。
  • 漸層填色、母版／版面配置（placeholder）尚未支援。
  • 自訂幾何在 PowerPoint 內沒有黃點，而且回不去內建形狀——這是 OOXML 格式本身的性質（在 PowerPoint 裡對內建形狀按「編輯端點」也會發生同樣的事）。清單裡挑得到的形狀就別用自訂幾何。另：一個自訂幾何只有一條路徑（做不到單一形狀內分區上色）、上限 400 個點、圓弧掃掠不超過一圈、座標夾在路徑框內（控制柄不能伸出框外）。子路徑挖洞已在畫布與匯出 XML 兩層驗過，但尚未用真實 PowerPoint 開過。圖形編輯器開啟時會把圓弧折成貝茲曲線（誤差 <0.01px，但按確定後換不回圓弧），不想被折就別用編輯器開它、改走 JSON。
  • 立體感形狀（立方體／圓柱／斜角…）畫布上的明暗只是近似；匯出走原生幾何，實際明暗由 PowerPoint 自己算。
  • 本機影片不會被嵌入——匯出的只是封面圖佔位，必須在 PowerPoint 手動換成真影片。這是刻意的：影片位元組會讓「整份 JSON 貼給 AI」這個用法失效。
  • 線上影片播放需要網路；且在 Keynote／Google Slides／LibreOffice 的支援程度尚未實測，可能只顯示封面圖。
  • 自動存檔存在這台電腦的這個瀏覽器裡（IndexedDB），換瀏覽器、換電腦、清除瀏覽資料都會不見，而且只保留最新一份（沒有版本歷史）。要留存或轉移請按「💾 另存」。無痕視窗通常擋存取，此時頂端會轉紅字明講。
  • 表格儲存格不支援格內混排：一格只能整格同一種格式。若某格需要「只有幾個字變色放大」，請把該格留空，另拉一個文字框疊在上面。疊上去的文字框不會跟著表格移動（建議與表格群組），也不會被格線裁切，內距請對齊儲存格。匯出後在 PowerPoint 裡可以直接把文字打回格內、刪掉覆蓋層——PowerPoint 的儲存格本身是支援格內混排的。
  • 自訂字型（fontFace）是整個元素統一覆寫；同一文字框內逐 run 混用不同字型請走 JSON。
  • 就地編輯只在 Chrome 實測過；Safari／Firefox 尚未測試，行為可能不同。
  • 轉場支援 Morph／淡出／推入／擦去（頁面屬性設定，進入該頁時播放）；Morph 依元素 id 跨頁配對，「複製此頁」保留元素 id 即為此用；元素進出動畫不支援。
