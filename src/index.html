使用說明

這是什麼

人與 AI 協作設計簡報的單檔工具：在 16:9 畫布上擺放文字、表格、圖片、形狀與 ECharts 圖表，匯出原生 PPTX，位置、大小、格式如實呈現（EMU 精確座標、行距鎖定）。全程本機處理。

與 AI 協作

  • 右上「JSON」＝整份簡報＋全域（標題／字體模式／字型）：複製給 AI 討論 → 貼回「套用」。
  • 右欄「本頁 JSON ▤」＝可拖曳的浮動面板，只顯示目前頁；面板開著時點畫布任一元素／圖片，會自動捲動並選取它的 JSON 區塊，適合針對性微調。
  • JSON 內圖片以 @asset:元素id 佔位顯示（base64 不塞爆視窗）；「套用」時自動還原位元組。新圖請由工具插入；存 .json 檔仍含完整圖片。
  • 細緻的格式（單一文字框內混用粗體／變色／上下標、儲存格個別底色、合併儲存格）由 AI 直接寫 JSON 達成；畫布上的編輯以整個元素為單位。
  • 圖表存的是 ECharts option 規格，不是死圖——隨時可改數據重渲染。

畫布操作

  • 點選→拖曳移動（有置中／邊界磁性吸附）；八個把手縮放；方向鍵微調（Shift=10px）；Delete 刪除；Cmd/Ctrl+D 複製元素。
  • 多選：Shift／Cmd 點擊加減選，或在空白處拖曳框選；多選後拖四角＝整組比例縮放（位置、尺寸、字級同步）、拖本體＝整組移動，右欄可輸入縮放 % 與對齊。
  • 雙擊文字／形狀＝編輯文字（右側面板也有純文字編輯框）；雙擊表格儲存格＝編輯內容；雙擊圖表＝編輯 option。
  • 「＋形狀」開啟圖庫：線條／基本／箭號／方程式／流程圖／星星綵帶／圖說，共 40+ 種。線條類（直線、箭頭、雙頭、肘形）選取後拖曳兩端圓點改方向，可水平、垂直、斜向；畫布預覽為近似圖形，匯出為 PPT 原生幾何。
  • 表格選取後：上緣／左緣藍色把手調欄寬列高；把手之間的灰色區段滑過變紅、點擊即刪除該欄／列（合併儲存格自動縮減，其餘欄寬列高不動）；右側面板「新增」加欄列。
  • 合併儲存格：表格選取後，在格子內拖曳反白要合併的相鄰範圍（會自動外擴，不切穿既有合併），點反白框旁的「合併儲存格」鈕；反白單一已合併格則點「取消合併」。此時移動整張表改由拖曳表格邊框帶（外圈約 16px）。雙擊某格＝編輯該格文字。
  • 逐格／多格改樣式：拖曳反白幾格後，右側面板的字級／行距／粗斜體／文字色／對齊／底色只套用到選取格（面板頂端會顯示套用範圍）；未反白則套用全表。框線為整表外框。
  • 格內編輯快捷：編輯儲存格時，Tab＝跳右一格（列尾自動換到下一列、跳過合併格）、Shift+Tab＝跳左一格、Enter＝跳下一格、Shift+Enter＝格內換行、Esc＝結束編輯。（PowerPoint 的 Enter 是格內換行；此處 Enter 改採試算表式跳下格，換行請用 Shift+Enter。）
  • 右欄「縮放 %」＝單一元素等比縮放（尺寸、字級、欄寬列高、線寬同步，可小數）；圖片與形狀另有角度／90°／水平垂直翻轉。
  • 物件拖出投影片外仍半透明可見、可拖回；超出區域僅供暫放，匯出時照座標輸出（會有超出警告）。
  • 圖片：「＋圖片」選檔，或直接把圖檔拖進畫布、貼上剪貼簿圖片；縮放固定等比。
  • ☰ 圖層面板（頂端按鈕，可拖曳）：列出當頁元素（上＝最上層），拖曳重排堆疊、👁 顯示／隱藏、🔒 鎖定（畫布不可選拖，仍可從面板點選）；點列選取（群組則選全組）。隱藏元素不渲染也不匯出。
  • 不透明度：右欄滑桿 0–100%，匯出轉 PPT 原生 transparency（圖片／形狀填色／框線／表格底色可調）。
  • 軟群組：多選後按「群組」；之後點群組任一成員即選全組並可整組移動／縮放，雙擊可進入編輯單一成員；單選面板或多選面板可「解散」。匯出時攤平為獨立元素。
  • 對齊分佈：多選面板有左/中/右、上/中/下對齊，及水平／垂直等距（需 ≥3 個，首尾固定、中間平均間隙）。
  • 格式刷：選來源元素按「🖌 複製樣式」武裝（游標變 copy、頂端提示），再點目標套用其字體／顏色／對齊／填色／框線／不透明度（不改內容與尺寸）；可連續套多個，Esc 取消。
  • 縮放：右欄滑桿 0.1–2.0×（停頓於 0.5／0.8／1.0／1.2／1.5），旁邊「含字級」勾選（預設開）；放開歸回 1.0×。寬高旁「比例鎖定／字級同步」勾選（預設關）影響數字輸入與拖曳 resize。
  • 行距：文字框與表格可設行距（×字級），匯出鎖為精確 spcPts；單格行距可透過 JSON 微調。
  • 形狀 adj 黃點：可調形狀選取後，畫布上會出現黃點，直接拖曳調整圓角／斜度／箭深／桿寬／尾標／肘形折點（同 PPT 手感，拖曳時顯示數值）；右欄滑桿可精修，匯出為 PPT 原生 avLst。形狀選單縮圖右上角有黃點者即支援。
  • 色票：所有選色開三頁籤面板——設計師精選（每組 5 色）／Open Color（14×10）／全色域調色盤。
  • 範本庫：頁面面板「📋 套範本」插入標題頁／兩欄／圖表頁等版型（文字帶 role）。Deck 合併「⧉ 合併 .json」把另一份簡報附加為後續頁。
  • 快照匯出：頂端「🖼 快照」輸出本頁或全部（zip）為 PNG／JPG，可選 1–3× 解析度。講者備忘稿在頁面面板編輯，匯出寫入 pptx。
  • 所有元素（表格除外）有淡虛線框顯示框尺寸；圖片／形狀旋轉後選取框與把手跟著轉（resize 已依旋轉換算，仍正確）。
  • 右側面板：座標尺寸（cm）、縮放 %、不透明、樣式、角度翻轉、層級（上移下移）、格式刷、複製、刪除。
  • 復原／重做：Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z（60 步）。

字體模式

  • 鎖定字體（預設）：匯出寫死 中文 Noto Sans TC／英數 Poppins／表格英數 Roboto。預覽＝輸出，折行位置最可靠。
  • 母版繼承：匯出寫 +mn-lt／+mn-ea 主題槽引用，貼到任何母版時由該母版字體接手（折行位置隨目的端字體浮動）。
  • 兩種模式都不按語言切 run、全文件 lang=zh-TW——xlsx2pptx 的中英交界異常換行病灶已拔除。
  • 預覽一律以三字體渲染；本機未安裝時連網會自動載入 Google Fonts，離線則以系統字體近似（建議安裝字體）。

匯出行為

  • 每頁一張投影片；文字框關閉 autofit、行距鎖定 1.2 倍字級精確值；表格為原生 PPTX 表格；圖片嵌原始位元組；圖表以 3× PNG 嵌入。
  • 每個元素的 pptx 形狀名稱＝其 JSON id（日後 Morph 轉場跨頁配對用）。
  • 右上 Mark 區與底部頁尾為預留區，內容侵入變紅警告（不阻擋）。
  • 使用方式：開啟匯出的 .pptx，整頁複製到目標簡報（目標需同為標準 16:9）。

已知限制

  • 母版繼承模式下折行位置由目的端字體決定，文字框寬度請留餘裕。
  • ECharts option 僅支援純 JSON（不含函式）。
  • 轉場支援 Morph／淡出／推入／擦去（頁面屬性設定，進入該頁時播放）；Morph 依元素 id 跨頁配對，「複製此頁」保留元素 id 即為此用；元素進出動畫不支援。
