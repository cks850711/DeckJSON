使用說明

這是什麼

人與 AI 協作設計簡報的單檔工具：在畫布上擺文字、表格、圖片、形狀、ECharts 圖表與影片，匯出原生 PPTX，位置、大小與格式如實呈現。全程在你自己的電腦上跑，不連任何外部網站——字體用的是你電腦上已經安裝的，不下載網路字體。

畫面上有什麼

  • 上方工具列：開新／開啟／存檔／另存、復原重做、插入（文字、表格、圖片、形狀、圖表、影片），右半是圖層、JSON、快照、全簡報設定、齒輪、匯出與說明。
  • 左側頁面欄：頁面縮圖，可拖曳重排，底部有「新頁」與「母版」。
  • 中間畫布：投影片本身。拖出邊界的東西會半透明留著，不會消失。
  • 右側屬性面板：內容隨你選了什麼而變——選了元素顯示它的設定，什麼都沒選就顯示頁面屬性。
  • 畫布右下的浮動列：縮放、適寬適高、格線與吸附。這一列是檢視設定，不跟著簡報檔走。

存檔

  • 自動存檔：每次改動後約 1 秒自動存進瀏覽器（IndexedDB），重新整理／關掉分頁再打開會自動還原，底部狀態列會顯示存檔時間。存不進去時（容量滿、無痕模式）會轉紅字明講原因，不會靜默失敗。
  • 開新（工具列最左那組）：清空重來，需連按兩次確認；還留一步 Cmd/Ctrl+Z 後路。開啟／存檔／另存（同一組）：讀寫 .deck 檔（內容仍是 JSON，舊的 .deck.json 照樣開得起來）。Cmd/Ctrl+S 寫回你開啟的那個檔，Cmd/Ctrl+Shift+S 換位置另存；底部狀態列會顯示目前檔名，● 代表有還沒存的變更。就地覆寫需要從 http://localhost 開啟（用專案根的 start-localhost.command）——瀏覽器不發寫入權給直接雙擊開啟的頁面，那種情況下存檔會退回「下載一份副本到下載資料夾」，提示列會明講。
  • 自動存檔只有一份、只在這台瀏覽器。重要進度請另存成檔案——那才是可備份、可轉移、可貼給 AI 的形式。

選取與搬移

  • 選一個：點它就好。拖曳搬移（靠近投影片中線與邊界時會磁性吸附住），四角與四邊中點共八個把手縮放，方向鍵微調（按住 Shift 一次走 10px），Delete 刪除，Cmd/Ctrl+D 複製一份。
  • 選很多個：Shift 或 Cmd 點擊加選減選，或在空白處拖曳框選——框到的都選起來。
  • 多選之後，拖四角是整組等比縮放，位置、尺寸與字級一起跟著變；拖本體是整組搬移。右欄可以直接填縮放百分比，也可以對齊。
  • 物件拖到投影片外面不會消失，會半透明留在那裡，隨時拖得回來。那塊只是暫放區，匯出時照座標輸出，並且會給你一則超出投影片的警告。
  • 除了表格，所有元素都有一圈淡虛線顯示框的實際大小——文字框沒填色時特別需要，不然你不知道它有多大。
  • 復原與重做：Cmd/Ctrl+Z 與 Cmd/Ctrl+Shift+Z，共 60 步。
進階：等比縮放取哪一軸
  • 等比只有一個比例，所以多選拖四角時，以指標移動較多的那一軸為準。
  • 單選時右欄的「縮放 %」是等比縮放，尺寸、字級、欄寬列高與線寬同步，可以填小數。

對齊、分佈與吸附

  • 對齊與分佈：多選後右欄有左／中／右與上／中／下對齊，還有水平與垂直等距——等距要選三個以上，頭尾不動，中間平均分。
  • 格線：畫布右下角浮動列的「格線」鈕開關。三個層次看得出遠近——一格是虛線，每 5 格一條細實線，每 10 格一條粗實線，原點在投影片左上角，格距預設 5mm。
  • 格距、細線與粗線的間隔格數、顏色（預設 #ADB5BD），都在格線鈕右半那個小箭頭裡調。開關與細部設定放在一起，不在右欄。
  • 吸附：同一列的「吸附」打開後，搬移只吸左緣與上緣；拖白色方點縮放則四邊都吸，表格的欄寬列高把手與線條端點也一樣。整組搬移吸的是包圍盒的左上角，組內相對位置不會變。
  • 輔助線贏過格線：投影片中線、四邊、預留區外緣的吸附一直都在，而且優先於格線。
進階：為什麼搬移只吸兩邊、什麼時候不吸
  • 四邊都吸的話，寬度不是格距整數倍的元素會在兩組吸附點之間被拉來拉去，手感很卡，所以搬移只吸左緣與上緣。
  • 格線密到幾乎處處可吸，不給輔助線優先權就再也對不到中線了。
  • 旋轉過的元素、以及等比鎖定時不吸——邊不平行於格線，吸了也對不齊。
  • 格線只活在畫布上：不匯出、不進快照、不寫進 .deck 檔，設定存在這台瀏覽器。

軟群組

  • 多選後按「群組」。之後點群組裡任何一個成員都會選到整組，可以整組搬移與縮放；雙擊可以進去改單一成員。要拆開，在單選或多選面板按「解散」。
  • 群組本身沒有座標，成員各自獨立。所以右欄那組 X／Y／寬／高指的是包圍盒：改 X／Y 是整組平移，改寬／高是以包圍盒左上角為不動點縮放整組，可以鎖比例，也可以連字級一起縮。
  • 匯出時群組會攤平成各自獨立的元素——PowerPoint 那邊看不到群組，位置與大小則完全一致。

圖層

  • 工具列右側的圖層面板（可以拖著移動）列出這一頁的所有元素，最上面就是最上層。拖曳可以重排堆疊順序。
  • 眼睛鈕是顯示／隱藏，鎖頭鈕是鎖定。鎖住的元素在畫布上點不到也拖不動，但還是可以從面板點選——被別的東西壓住時就靠這個。
  • 隱藏起來的元素不會渲染，也不會匯出。
  • 點一列就選取它；如果它在群組裡，會選到整組。

格式刷、縮放與不透明度

  • 格式刷：選好來源元素，按右欄底部的複製樣式（刷子圖示）武裝起來——游標會變成 copy，頂端也有提示——再點目標，就套上來源的字體、顏色、對齊、填色、框線與不透明度，內容與尺寸不動。可以連續套很多個，Esc 取消。
  • 縮放：右欄滑桿 0.1 到 2.0 倍，在 0.5／0.8／1.0／1.2／1.5 有停頓，旁邊「含字級」預設打開；放開後歸回 1.0。寬高旁邊的「比例鎖定」與「字級同步」預設是關的，會影響你直接填數字與拖把手的結果。
  • 不透明度：右欄滑桿 0 到 100%，匯出成 PowerPoint 原生的透明度（transparency）。圖片、形狀填色、框線、表格底色都可以調。
  • 圖片與形狀另外有角度、一鍵順時針 90°、以及水平／垂直翻轉。旋轉之後選取框與把手會跟著轉，縮放已經依角度換算過，拖起來仍然正確。

右欄怎麼分組

右欄的分頁依你選了什麼而變。找不到某個設定時，先確認自己選的是不是對的東西。

選取的東西右欄的分頁
文字框版面／文字／段落／效果
形狀版面／形狀／效果
圖片版面／圖片／效果
表格版面／表格／儲存格（沒有效果頁）
多選或群組不分頁：位置尺寸（包圍盒）、版面、對齊與分佈、群組與動作
什麼都沒選不分頁：頁面樣式、章節、備忘稿、範本與合併
  • 版面頁固定是位置尺寸、變形、排列三段。X 上方可以把單位切成 px／pt／cm，預設 px。
  • 效果頁是超連結與陰影。表格沒有這一頁——空的分頁會被拿掉，不會留一個點進去沒東西的空殼。
  • 右欄最底下釘著動作列：格式刷、複製、本頁 JSON、刪除。它不參與分頁，永遠在那裡。
  • 整份簡報層級的設定（投影片尺寸、字體、頁碼、預留區、環境設定檔）不在右欄，在工具列的「全簡報設定」裡；格線則是這台瀏覽器的檢視設定，在格線鈕旁邊。

就地編輯

  • 雙擊文字框或形狀就開始改字，粗體、顏色、高亮看得見也改得動。雙擊表格儲存格是改內容，雙擊圖表是改 option。
  • 反白幾個字，右欄的格式按鈕就只套那幾個字；沒反白就是整個文字框。
  • 編輯途中點右欄的按鈕不會中斷編輯，反白的範圍也留著——設完一項可以接著設下一項。
  • 右欄那個純文字編輯框是「整框換掉」用的捷徑，會清掉框裡的混排格式。偵測到混排時會先問你一次。要保留格式，請在畫布上就地改。

字元樣式

在右欄的「文字」分頁（文字樣式）與「段落」分頁（字元進階）。選了文字框才會出現這兩頁。

  • 粗體、斜體之外還有 U 底線、S 刪除線、高亮（像螢光筆塗一塊底色），以及上標與下標。
  • 「字元進階」裡有字距、自訂字型（只蓋掉這一個元素，留空就沿用全域字體設定）、描邊與輝光。
  • 每一項都可以只套在反白的那幾個字上。同一句話裡混用粗體、顏色與字級都沒問題。
  • 匯出之後在 PowerPoint 裡，那句話仍然是同一個文字框裡的同一句話，不會被切成好幾個文字方塊。
進階：匯出對應
  • 以上都寫成 PowerPoint 原生的字元屬性，不是畫出來的效果。
  • 行距匯出時鎖成精確值（spcPts），不隨目的端字體浮動；單一儲存格的行距可以從 JSON 微調。

段落

  • 項目符號與編號：「段落」區可以切成無、• 符號、1. 編號，再用 − 與 ＋ 調縮排層級。每一層 18pt，就是 PowerPoint 預設的 0.25 吋，且是懸掛縮排——文字換行後會對齊到第一行的文字，不會跑到符號底下。
  • 匯出成原生的清單（buChar／buAutoNum），在 PowerPoint 裡還是真的清單，不是手打的符號。
  • 段前與段後間距跟行距是分開的兩件事：行距管一段內部每一行的高度，段前段後管兩段之間的空隙。
  • 行距以「×字級」計算，文字框與表格都可以設。

超連結、直書與內距

  • 超連結：填網址，或填 #3 直接跳到本簡報第 3 頁。設了連結的文字會自動加底線，顏色仍照你設的文字色。
  • 直書與文字方向：文字框與形狀可以選直書（中日韓）、旋轉 90°／270°、蒙文直書。這是文字在框裡轉向，框本身不轉——要轉整個框請用「旋轉」。直書時中文直立、英數躺下，跟 PowerPoint 一致，就地編輯照常可用。
  • 文字框內距：有填色的卡片式文字框加了內距就不會貼邊。不自動換行適合單行標籤，框會跟著字長。
進階：這幾項的匯出對應
  • 連結底線是 PptxGenJS 一律補的 u="sng"，畫布同步顯示，所以預覽就是結果。
  • 直書匯出為原生 <a:bodyPr vert>；內距為 lIns/tIns/rIns/bIns；不換行為 wrap="none"。

給 AI 的簡寫

  • JSON 的段落可以只寫 "md" 代替 runs，支援 **粗體**、*斜體*、~~刪除線~~、==高亮==、[文字](網址)，其中 [文字](#3) 是跳到第 3 頁。
  • 套用時會展開成正式的 runs 並把 md 移除，存檔裡不會留下 markdown。
  • text 欄位永遠是字面文字，不會被解析。所以內容本來就含 ** 也不會被改壞。

欄列與合併

  • 調欄寬列高：選取表格後，上緣與左緣會出現藍色把手，拖曳就能調。要加欄或加列，用右欄「表格」分頁→「結構」的「＋欄」「＋列」。
  • 刪掉整欄或整列：把手之間的灰色區段，滑過會變紅，點一下就刪掉。合併過的儲存格會自動縮減，其他欄寬列高不受影響。

合併儲存格

合併是按畫布上浮出來的鈕，不在右欄。右欄「表格」分頁的「合併」段只放操作提示，沒有按鈕。

  • 怎麼合併：在格子裡拖曳，反白要合併的那幾格，按反白框旁浮出來的「合併儲存格」。
  • 不會切壞既有的合併：反白範圍如果只蓋到某個合併格的一半，範圍會自動往外長，把它整塊包進來再合併。
  • 取消合併：反白單一一個已經合併的格子，那顆鈕會變成「取消合併」，按下去就拆回原本的格數。
  • 搬動整張表要抓外圈：格子內部已經讓給拖曳反白了，所以搬移整張表請抓最外圈那一圈邊框（約 16px 寬）。想改某一格的文字，雙擊它。

只改某幾格的樣式

這一節的設定都在右欄的「儲存格」分頁底下。選取表格後，右欄會出現版面／表格／儲存格三個分頁：版面管整張表在頁面上的位置與大小，表格管欄列結構與合併，儲存格管格子裡的樣式與框線。

  • 拖曳反白幾格，「儲存格樣式」的字級、行距、粗斜體、文字色、對齊、底色與框線，就只作用在那幾格。
  • 那一段的第一行會寫現在套到哪裡——是整張表，還是反白的幾格（連是哪幾格都寫出來），不用自己猜。
  • 沒反白就是整張表。點畫布別的地方取消反白，就回到全表。

框線

同樣在「儲存格」分頁，「儲存格樣式」下面那一段。

  • 先設筆，再選邊：用右欄的「框線筆」設好線寬與顏色，再點全部、外框、內部，或上下左右單邊。「無」是清掉框線。
  • 套用範圍和樣式一樣：有反白就只套那幾格，沒反白就是整張表。
  • 虛線：筆旁邊勾「虛線」再按，畫出來就是虛線。實線虛線可以逐格逐邊混用。
  • 每一格的四邊各自獨立；相鄰兩格的共用邊會自動同步，所以畫布上看到的就是匯出結果。

只改格子裡的幾個字

還是「儲存格」分頁。「格內文字（反白處）」那一段只在格內有反白時才出現，沒反白時整段不會顯示，所以找不到它通常是因為還沒反白。

  • 雙擊進入儲存格，反白那幾個字，「儲存格樣式」的字級、粗體、斜體與文字色就只套在它們身上。取消反白就回到整格。
  • 有反白時會多出一排「格內文字（反白處）」：上標、下標、底線、刪除線、高亮，還有把反白處退回整格樣式的「清除格式」。
  • 上下標只有這條路：整格層級沒有上下標這兩個開關，化學式與科學記號都得從這排設。
  • 格內編輯的按鍵：Enter 是在格子裡換行，跟 PowerPoint 一樣；Esc 結束編輯。Tab 不跳格，要換格請直接雙擊目標格。

從別的軟體貼表格進來

  • 從 Excel、PowerPoint、Word 或網頁複製表格，直接 Cmd/Ctrl+V 貼進畫布，會變成可以編輯的原生表格，不是一張圖。合併儲存格、底色、字色、粗斜體、對齊、上下標與格內高亮都會保留，欄寬照來源。
  • 字級一律重設為 12pt，不繼承來源。來源的字級多半是為了把表格塞進版面而縮過的，那是別人的妥協，不是內容本身的階層。要整體改大小，選取整張表拖把手，並打開「比例鎖定」與「字級同步」——欄寬列高與字級會一起縮，結構不會跑掉。
  • 來源沒指定底色的格子會填白。貼進來的字通常是深色，透明底疊到深色背景上會整張看不見。想讓背景透出來，齒輪（偏好設定）裡可以關掉「白底」；已經貼進來的表格，選取整張表用右欄的「儲存格 → 底色」一次改完。
  • 格子裡的圖片會變成獨立的圖片元素，和表格綁成一個軟群組。整組搬移或等比縮放時圖會跟著走，但單獨拖某一欄的寬度時不會跟。這不是偷懶——PowerPoint 的儲存格本來就放不了圖片，它自己「在格子裡插入圖片」也是浮在表格上方的獨立物件。
進階：來源差異與匯出對應
  • Office 複製時會順便附一份圖像版本，本工具刻意讓表格優先。真的想要圖片版，先貼到別處再截圖。
  • Markdown 表格要先轉成 HTML 表格再貼——任何能把 Markdown 表格以 text/html 放進剪貼簿的工具都吃得到。圖片必須是內嵌的 data: URI 才帶得過來，遠端網址的圖會被略過。
  • 框線不從來源反推，因為 Excel 會把網格線也寫成 border。一律套整表細線，需要再自行調整。
  • 只收內嵌位元組（data:）的圖片。網頁上那種遠端網址的圖沒辦法隨簡報帶走，會略過並告訴你略過幾張。
  • 每一格的四邊、顏色與線寬各自獨立，與 PowerPoint 的儲存格框線相同。相鄰的共用邊會自動雙寫同步，所以畫布上看到的就是匯出結果。
  • 虛線框線匯出為 prstDash sysDash。

插入與調整

  • 按「＋形狀」開圖庫，共 176 種，分成線條、矩形、基本圖案、箭號、方程式、流程圖、星星綵帶、圖說與動作按鈕九組，等同 PowerPoint 內建的整份清單。上方可以用中文名或英文 key 搜尋。
  • 畫布上看到的輪廓就是 PowerPoint 的原生幾何本身——由 OOXML 的 preset 定義即時算出來的，不是外型接近的替代圖形。
  • 線條類（直線、箭頭、雙頭、肘形）選取後拖兩端的圓點改方向，水平、垂直、斜的都可以。

黃點微調

  • 可調的形狀選取後，畫布上會出現黃點，直接拖就能改圓角、斜度、箭深、桿寬、尾標、角度、肘形折點——跟 PowerPoint 同一套手感，拖曳時會顯示百分比。
  • 右欄的滑桿可以精修到小數。176 種裡有 114 種有黃點，圖庫縮圖右上角有黃點記號的就是。
  • 沒動過的黃點不寫進檔案，交給 PowerPoint 用它自己的預設值。

形狀裡的文字擺在哪

  • 形狀裡的文字不是擺在整個外框裡，而是照 OOXML preset 各自定義的文字區——星形的字在星芯、箭號的字在箭桿、梯形的字在上下底之間，而且會跟著黃點連動。
  • 187 種形狀裡有 137 種的文字區不是整個框。文字太長時會照 PowerPoint 的行為溢出文字區，不會被裁掉。
  • 這是畫布預覽的修正：匯出的 pptx 一直都是照 preset 擺，之前是畫布在騙人。所以既有簡報的匯出結果不會有任何改變。

線型與漸層

  • 線型：形狀外框、線條與文字框框線可以選實線、點線、虛線、長虛線、點虛線、長點虛。表格框線另有自己的實／虛線開關。
  • 漸層填色：文字框與形狀勾了「漸層填色」之後，可以選線性（角度可調，0° 是由左至右）或放射狀，2 到 6 個色標各自可調顏色與位置百分比。
  • 勾了漸層之後「底色」就不生效了——OOXML 的填色一次只能有一種，這是格式本身的限制。
進階：匯出對應
  • 線型匯出為原生 prstDash；漸層為原生 <a:gradFill>，在 PowerPoint 內可以再調。
  • 黃點匯出為 PPT 原生 avLst。

自訂幾何（custGeom）

  • 圖庫最後一組是自訂幾何，給清單裡找不到的異形用——不規則色塊、自訂折線、資訊圖區塊。插入後直接開圖形編輯器。
  • 已經存在的自訂幾何，選取後按右欄「形狀 → 幾何」的開啟圖形編輯器。
  • 只想改內建形狀的一兩個角，不必從零重畫：按「形狀 → 幾何」的轉成可編輯端點，形狀會原地拆成端點並開啟編輯器，外觀完全不變（187 種全部驗過，最大偏差 0.04px）。
  • 這個轉換跟 PowerPoint 的「編輯端點」一樣是單向的：黃點會消失，也換不回內建形狀。如果該形狀原本各部分的填色或外框設定不同（動作按鈕、圖說外框那類），轉換後只會剩一種填色，對話框會先告訴你。

圖形編輯器

  • 鋼筆：點一下是角點，按住拖是帶曲度的平滑點，點回黃色起點就閉合。Esc 或雙擊結束之後再點，就是新的一條子路徑。
  • 編輯點：拖錨點移動，拖控制柄調曲度（按住 Alt 拖會把兩側拆開成折角），點線段會在正中插一個節點，雙擊錨點切換直線與曲線，Delete 刪點。
  • 另有格線吸附（間距可選），以及編輯器內獨立的 Cmd/Ctrl+Z——在編輯器裡復原不會動到畫布上的其他東西。
  • 編輯器不擋畫布、可以拖標題列移開，方便對照形狀在整頁裡的大小與位置。
  • 挖洞：在外圈裡面再畫一條子路徑就會空心。繞行方向不影響結果，PowerPoint 用的是 even-odd 填充規則。
  • 自訂幾何會跟著形狀縮放：座標活在形狀自己的路徑座標空間裡，拉大拉小圖案等比跟著變，跟內建形狀的行為一致。
進階：也可以用 JSON 或請 AI 畫
  • 在 JSON 面板改 points，指令有 moveTo、直線、二次貝茲、三次貝茲、圓弧與 close。
  • 路徑座標空間是 pathW／pathH，不是像素。

插入圖片

  • 按「＋圖片」選檔，或直接把圖檔拖進畫布，或貼上剪貼簿裡的圖。縮放固定等比，不會拉變形。
  • 物件超連結：形狀、圖片、圖表與線條都可以設「整個物件可點」的連結，填外部網址或 #3 跳頁，另外可以填滑鼠移上去時的提示文字。文字框裡個別文字的連結請用「文字樣式 → 超連結」。
  • 替代文字：填了之後匯出為無障礙描述（descr）。

裁切

  • 預設是「完整」——整張塞進框裡，強制等比不變形。
  • 雙擊圖片（或按「裁切…」）進入裁切模式：拖曳移動構圖、滾輪縮放、Enter 完成。
  • 被裁掉的部分會變暗而不是消失，你看得到自己捨棄了什麼。
  • 裁切模式下拉外框只動裁切窗，圖片釘住不動，跟 PowerPoint 一致。
  • 圖片可以拖出框外做留白，用來裁出單邊或四周的空白。至少會保留一成的重疊，不會整片空白到找不到圖。
  • 被裁掉的部分只是不顯示，原圖完整留在檔案裡，隨時可以按「完整」還原。另有圓形裁切。
  • 構圖存成四邊的比例，匯出為原生 srcRect，在 PowerPoint 裡還可以再調。

陰影

  • 文字框、形狀、圖片與圖表的「陰影」區勾選後，可以調顏色、模糊、位移、方向與濃度。
  • 匯出的是 PowerPoint 原生陰影（outerShdw），不是把陰影畫進圖裡，所以在 PowerPoint 內還可以再調。
  • 畫布是用 CSS filter 預覽的，所以快照 PNG 不會有陰影——那是 html2canvas 不支援 filter，不是設定沒生效。

壓縮

  • 屬性面板列出三個檔位，分別是顯示尺寸的 1.5、2、3 倍（約 144、192、288 PPI）。按鈕上直接標出會變成幾×幾、幾 KB，原圖不夠大的檔位會自動停用。
  • 沒用到透明的圖轉成 JPEG，有透明的維持 PNG。刻意不用 WebP 與 AVIF——PowerPoint 舊版不認得。
  • 這個操作不可逆（但可以 Undo），而且一律要你按下才執行，存檔不會偷跑。

影片

  • YouTube 連結：匯出為 PowerPoint 原生的線上影片。pptx 裡只有封面圖，影片走外部連結，所以播放需要網路。
  • 本機影片：不嵌入位元組，只自動抓一格畫面當封面，並記下檔名與長度。匯出後會跳出「待插入影片」清單，請在 PowerPoint 對照該框插入真的影片。
  • 同一份提示也寫進了該元素的替代文字與那一頁的備忘稿，所以就算清單關掉了，資訊還在檔案裡。
  • 封面隨時可以換成自己的圖。

圖表

  • 圖表存的是 ECharts option 規格，不是一張死圖——隨時可以改數據重新算。
  • 分工是：資料交給 JSON（自己寫，或請 AI 產），外觀用「視覺編輯」分頁調。
  • 面板不擋畫布、可以拖標題列移開，改動即時反映在畫布上的圖表本身——面板裡沒有另一個小預覽，你看的就是結果。
  • 底部兩顆鈕：套用寫入之後面板留著（只在 option JSON 分頁有作用），確認寫入並關閉。
  • 面板只寫它自己那幾格，你手寫的進階設定不會被覆蓋。
視覺編輯能調哪些
  • 圖種；圖表與座標軸標題（字級、顏色）；軸線與刻度（顏色、粗細）；軸標籤（字級、顏色、傾斜）。
  • 數值軸範圍與刻度間隔、反轉；主格線（顏色、線寬、虛線）；圖例；資料標籤（位置、字級、顏色）。
  • 系列顏色與邊框、柱寬、線寬、端點；圓餅內圈與起始角；繪圖區留白；圖表底色。

原生圖表還是 PNG

  • 圖表可以選擇匯出為 PowerPoint 原生圖表（在 PPT 裡能編輯資料、跟隨目標母版），或維持 PNG（外觀與畫布完全一致）。
  • 沒有 PowerPoint 原生對應的設定（長條圓角、副格線、隱藏數值軸標籤）標示「僅 PNG」。勾了「匯出為原生圖表」時會直接停用，不讓你設一個匯出時會消失的值。

單頁的設定

在右欄——畫布上什麼都沒選的時候，右欄顯示的就是頁面屬性（頁面樣式、章節、備忘稿、範本與合併）。

  • 頁面背景圖：「頁面 → 背景圖」選圖，滿版拉伸、壓在所有元素底下。想要局部裁切或只露一角，請改用一般圖片元素鋪滿整頁。
  • 不放映此頁：「頁面樣式」勾起來之後，那一頁還在檔案裡，只是放映時跳過。縮圖會壓暗並標示，你不會忘記自己藏了一頁。
  • 講者備忘稿：「頁面 → 備忘稿」寫，匯出時寫進 pptx，在 PowerPoint 的備忘稿窗格看得到。
  • 快照：工具列右側的「快照」把本頁或全部輸出成 PNG／JPG（全部會打包成 zip），解析度可選 1 到 3 倍。
進階：匯出對應
  • 背景圖為原生 <p:bg>；不放映為 <p:sld show="0">。

章節

  • 「頁面 → 章節」勾「從本頁開始新章節」，這一頁到下一個章節起點之間的頁面就同屬一章，左側頁面清單會出現分隔列。
  • 匯出為 PowerPoint 原生章節，在縮圖窗格可以整段摺疊、搬動、隱藏，或從該段開始放映。
  • 只影響編輯時的導覽，投影片內容與放映完全不變。
  • 章節名必須唯一，撞名會自動補「(2)」——PowerPoint 是靠名稱認章節的。
  • 如果你從第 5 頁才開始分章，前面四頁會自動歸進一個以簡報標題命名的章節，不會變成無主的頁。

範本與合併

  • 套範本：「頁面 → 範本與合併」插入標題頁、兩欄、圖表頁等版型，文字帶著 role 標記，方便 AI 認得哪一格是標題。
  • 合併簡報：「⧉ 合併簡報」把另一份 .deck 附加成後續頁。
  • 色票：所有選色的地方都開同一個三頁籤面板——設計師精選（每組 5 色）、Open Color（14×10）、全色域調色盤。

整份簡報的設定

在工具列齒輪左邊那顆「全簡報設定」鈕裡，不在右欄。判準是：跟著簡報 JSON 走的放這裡；只存在這台瀏覽器的偏好（介面語言、貼上白底）放齒輪；檢視類的（格線、母版元素標記）放畫布右下的浮動列。

  • 投影片尺寸：16:9、4:3、16:10 或自訂 px。改尺寸不會自動搬動既有元素，要自己重排。
  • 字體：中文、英數、表格英數三個槽，填你電腦上已經安裝的字體名。畫布即時反映，匯出寫同一個名字。沒安裝時頂端會提示「預覽用替代字體，匯出仍寫原字體名」——所以預覽不準不代表匯出會錯。
  • 語言：寫進每個文字 run，決定 PowerPoint 用哪一國的拼字檢查。預設跟隨瀏覽器語言。
  • 檔案資訊：作者、公司、主旨，連同標題寫進 pptx 的檔案屬性，在 Finder 或 PowerPoint 的「資訊」看得到。留空的欄位就不寫入。
  • 頁碼與日期：勾選後可以各自選左下、中下、右下，以及字級、顏色、首頁不顯示。日期另外可以選自動更新（開檔時重算）或固定文字。
  • 匯出為 PowerPoint 原生的頁尾佔位符，頁碼是可更新的欄位，插入或刪除頁面會自動跟著變。畫布上兩者都是預覽，點不到也選不起來。
  • 預留區：母版上不該被壓到的區域（Logo 位、頁尾），可以自己加自己刪。它只是畫布上的輔助線與吸附，元素壓到會變紅警告但不會擋你，也不寫進 pptx。預設一個都沒有。
  • 環境設定檔：把這個面板裡的設定整包匯出成 .profile.json，或載入套用，也可以「設為新簡報預設」記在這台瀏覽器。這些設定同時也存在簡報 JSON 裡，所以貼給 AI 再貼回來不會掉。
進階：頁碼與日期的匯出對應
  • 自動更新的日期是 <a:fld type="datetime1">；頁尾佔位符是 <p:ph type="sldNum"> 與 type="dt"。
  • 語言寫在每個 run 的 lang。

母版（信紙）

  • 按左側頁面欄底部的「母版」進入（沒啟用時那顆鈕會一併啟用）。畫布會切成母版編輯狀態：整圈橘色框，底部有橘色提示列，你不會搞不清楚自己在改哪裡。
  • 放進去的元素會出現在每一頁，改一次全部跟著變。一般工具全部照用——文字、形狀、圖片、圖表、漸層、陰影、超連結、自訂幾何都行。
  • 單一頁面可以勾「本頁不套母版」，封面常常需要。
  • 匯出方式二選一，切換只改一個旗標、不動母版內容，可以隨時來回比較：
    • 放在母版上：寫進 PowerPoint 的版面配置，檔案最小。代價是單張投影片複製到別的簡報時，母版內容不會跟著走。
    • 畫進每一頁：匯出時把母版內容實際畫成每一頁的圖形，整張搬得走。代價是圖片的位元組每頁各存一份，檔案會變大。
  • 母版元素的 id 不可以跟頁面元素撞名，撞到時會自動改頁面那一邊。

樣式模式

同一個開關管兩件事：字體與頁尾佔位符（頁碼／日期）。兩者的取捨是同一個——要嘛「貼到哪都長一樣」，要嘛「入境隨俗」。

  • 鎖定樣式（預設）：字體寫死你設定的三個字體名，頁碼與日期寫死座標與字級。預覽就是輸出，折行位置最可靠。
  • 母版繼承：字體改成引用主題槽，頁碼與日期寫成不帶座標的空殼佔位符。貼到任何母版時，字體、頁尾的位置與字級都由那個母版接手；代價是折行位置會隨目的端的字體浮動。
  • 繼承模式下，這個檔自己打開時仍然是正確的——完整座標寫在自家母版裡，投影片與版面配置沒寫的部分會往上一層找。
  • ⚠ 繼承模式不適用於「放在母版上」：那個模式的版面配置承載你的 Logo 與頁尾條，必須維持自訂，才不會在貼上時被目的端的版面配置取代——代價是頁碼與日期也跟著繼承不到。要兩者兼得，請改用「畫進每一頁」。
進階：主題槽與 lang
  • 母版繼承的字體寫成 +mn-lt／+mn-ea 主題槽引用。
  • 兩種模式都不按語言切 run、全文件同一個 lang——中英交界不會出現異常換行（那是人為切 run 躲過避頭尾造成的）。

兩個 JSON 入口

  • 右上的「JSON」是整份簡報加上全域設定（標題、字體模式、字型、語言、投影片尺寸、預留區）。複製給 AI 討論，改完貼回來按「套用」。環境設定跟著 JSON 走，所以貼來貼去不會掉。
  • 右欄底部的「本頁 JSON」是可以拖著移動的浮動面板，只顯示目前這一頁。面板開著的時候點畫布上任何一個元素，它會自動捲到並選取那個元素的 JSON 區塊，適合針對某一個東西微調。

圖片怎麼處理

  • JSON 裡的圖片以 @asset:元素id 佔位顯示，base64 不會把視窗塞爆。按「套用」時自動還原成位元組。
  • 要加新圖請用工具插入，不要自己在 JSON 裡貼 base64。存成 .deck 檔時仍然含完整圖片。

要貼給外部工具的時候

  • 本頁 JSON 面板的「複製（含 base64）」是不遮罩圖片的複製，給能讀 deck JSON 的外部工具用。
  • @asset 佔位只有本簡報自己還原得回位元組，貼到外面會變破圖，所以外部工具要用這一顆。
  • 注意它仍然是單頁片段：不含 stage、fonts、master，外部工具會套自己的預設值。

哪些細節可以交給 AI 寫

  • 文字框或表格儲存格裡混用粗體、變色、上下標、底線、高亮、逐段項目符號，儲存格個別底色，合併儲存格——這些都可以由 AI 直接寫 JSON。
  • 同樣的東西也都可以在畫布上反白幾個字就地改。兩條路走的是同一份資料，不會有「AI 寫的」與「手改的」兩種格式。

匯出行為

  • 每一頁對應一張投影片。文字框關閉 autofit、行距鎖成 1.2 倍字級的精確值；表格是原生 PPTX 表格；圖片嵌原始位元組；圖表以 3 倍解析度的 PNG 嵌入（或原生圖表，見〈圖表〉）。
  • 使用方式：開啟匯出的 .pptx，整頁複製到你的目標簡報。目標簡報的投影片尺寸要跟這裡設的一樣，否則會被縮放。
  • 每個元素在 pptx 裡的形狀名稱就是它的 JSON id，這是給 Morph 轉場跨頁配對用的。
進階：匯出後修掉了什麼
  • PptxGenJS 3.12 有幾個結構性缺陷會讓 PowerPoint 判為檔案毀損並要求修復，匯出後一併修掉：段內混排時重複輸出 <a:pPr>、形狀 id 撞號、物件超連結沒註冊關聯而寫出懸空的 rIdundefined、備忘稿基建畸形。
  • 頁尾佔位符（頁碼／日期）是另外自己寫的，不走 PptxGenJS——它只會寫死座標的版本，沒辦法繼承目的端母版。

還沒做到的事

這一頁列的是目前做不到或還沒驗證的事，不是操作說明。遇到怪現象時先來這裡對一下。

母版與樣式模式

  • 母版繼承模式下，折行位置由目的端字體決定，所以文字框寬度請留餘裕。
  • 母版繼承的頁碼與日期在「放在母版上」模式下不生效，原因見〈樣式模式〉。
  • 目的端如果沒在「插入 → 頁首及頁尾」勾選日期，貼過去的日期會被目的端隱藏——那不是缺陷。
  • 母版只做「共用元素」一層（Logo、頁尾、裝飾），不做內容 placeholder（PowerPoint 那些「按一下以新增標題」的洞）。內容 placeholder 的位置與字級繼承自版面配置，投影片貼到別的簡報時會跳位，與本工具「所見即所得」的前提相衝。例外是頁碼與日期：那兩個本來就該跟著目的端頁尾走，所以做成真正的佔位符，並用「樣式模式」讓你選要不要繼承。頁尾文字（ftr）還沒做。
  • 「放在母版上」匯出時，母版內容不會跟著單張投影片被複製到別的簡報——母版物件不屬於任何一張投影片。需要帶著走請改選「畫進每一頁」。兩種模式都還沒用真實 PowerPoint 開過。

形狀與漸層

  • 漸層只有線性與放射狀兩種、最多 6 個色標。PowerPoint 的路徑漸層與漸層外框不支援。
  • 立體感形狀（立方體、圓柱）套漸層時，各面的明暗會被漸層取代——OOXML 的填色只能有一種。
  • 立體感形狀在畫布上的明暗只是近似。匯出走原生幾何，實際明暗由 PowerPoint 自己算。
  • 自訂幾何在 PowerPoint 內沒有黃點，而且回不去內建形狀——這是 OOXML 格式本身的性質，在 PowerPoint 裡對內建形狀按「編輯端點」也會發生同樣的事。清單裡挑得到的形狀就別用自訂幾何。
  • 一個自訂幾何只有一條路徑，做不到單一形狀內分區上色；上限 400 個點；圓弧掃掠不超過一圈；座標可以伸出路徑框但不超過框外一倍（圖說尾巴、括號都靠這個）。
  • 子路徑挖洞與伸出框的負座標已經在畫布與匯出 XML 兩層驗過，但還沒用真實 PowerPoint 開過。
  • 圖形編輯器開啟時會把圓弧折成貝茲曲線（誤差小於 0.01px，但按確定後換不回圓弧）。不想被折就別用編輯器開它，改走 JSON。

圖表、影片與陰影

  • ECharts option 只支援純 JSON，不含函式。
  • 原生圖表只涵蓋有 OOXML 對應的圖種（柱狀、橫條、折線、區域、圓餅、環圈、散布）。桑基、儀表板、熱力圖等一律走 PNG。原生模式下框內排版由 PowerPoint 決定，與畫布不會完全一致，也不支援陰影與超連結。
  • 本機影片不會被嵌入，匯出的只是封面圖佔位，必須在 PowerPoint 手動換成真影片。這是刻意的——影片位元組會讓「整份 JSON 貼給 AI」這個用法失效。
  • 線上影片播放需要網路，而且在 Keynote、Google Slides、LibreOffice 的支援程度還沒實測，可能只顯示封面圖。
  • 陰影在快照 PNG 不呈現（html2canvas 不支援 CSS filter）。匯出 pptx 不受影響。

文字與表格

  • 自訂字型是整個元素統一覆寫；同一個文字框內逐 run 混用不同字型請走 JSON。
  • 表格儲存格的格內混排（粗斜體、顏色、字級、上下標、底線、刪除線、高亮）可以走 JSON 的 runs（也吃 md 簡寫），或雙擊進格反白幾個字再按右欄。上下標沒有格層級的對應，只能反白後從「格內文字」那排設。
  • 整格套用（沒反白）會清掉所有 run 對該項的覆寫，這跟 PowerPoint 的行為一致。

存檔與瀏覽器

  • 自動存檔存在這台電腦的這個瀏覽器裡（IndexedDB）。換瀏覽器、換電腦、清除瀏覽資料都會不見，而且只保留最新一份，沒有版本歷史。要留存或轉移請另存成檔案。
  • 無痕視窗通常擋存取，這時頂端會轉紅字明講，不會靜默失敗。
  • 就地編輯只在 Chrome 實測過，Safari 與 Firefox 還沒測試，行為可能不同。

轉場

  • 支援 Morph、淡出、推入、擦去，在頁面屬性設定，進入該頁時播放。
  • Morph 依元素 id 跨頁配對，「複製此頁」保留元素 id 就是為了這個。
  • 元素進出動畫不支援。
